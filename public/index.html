      予定

      通常のURLは閲覧専用です。最初に今月を表示します。月間・2週間はどちらも日曜〜土曜の7列です。月間は前月・翌月、2週間は当週の日曜から14日間を前後へ移動します。「今日」で現在の期間へ戻れます。

      日付と固定時間割は各セルの先頭行、追加見出し・備考はその下に表示します。長い予定は一覧で省略されます。日付を選ぶと下の詳細で全文を確認できます。

      固定・追加予定

      取り込まれた午前・午後の科目は固定時間割です。PIN編集でも変更できません。追加予定は午前・午後の見出しと内容、備考です。固定時間割を保持したまま個別に編集できます。

      編集

      「編集する」から編集者名と編集用PINを入力します。午前・午後の編集ボタンで見出し・内容のダイアログを開き、「保存」で共有します。「キャンセル」・閉じる・Escapeは保存せず戻ります。備考は入力から500ms後に自動保存します。日本語変換中は送信しません。

      編集者名は40文字以内、見出しは120文字以内、内容・備考は3000文字以内です。PINはページのメモリだけに保持され、ページを閉じると消えます。認証が切れた場合はPINを入力し直します。コマの編集ダイアログ内でも再認証できます。

      JSON取込

      1. 未保存の日別入力を保存し、コマの編集ダイアログを閉じます。
      2. 編集画面の「JSON取込」にJSONを貼り付けるか、JSONファイルを選びます。
      3. 「検証・プレビュー」で日付と更新値を確認します。
      4. 指定項目の既存値が更新されることを確認し、「この内容で取り込む」を押します。

      追加予定JSONの雛形を利用できます。例：

      {
  "entries": [
    {
      "entry_date": "2026-10-06",
      "slot1_title": "午前の持ち物",
      "slot1_content": "作業手袋を持参",
      "slot2_title": "午後の連絡",
      "slot2_content": "道具を確認",
      "note": "雨具を持参"
    }
  ]
}

      日付はYYYY-MM-DDで指定します。1〜31日、重複日付は不可、JSONと送信リクエストは256KiB以内です。指定できる更新項目は上の例の5項目だけです。見出しは120文字、内容・備考は3000文字以内。不正な日付・型・未知の項目は拒否します。

      指定した項目は既存値を上書きします。省略項目と固定時間割は保持します。空文字 "" はその欄を空にします。各日に更新項目を1つ以上指定してください。入力を変えると古いプレビューは無効になるので、もう一度検証してください。

      保存・再試行

      日別編集の通信失敗では入力を保持します。「未保存の予定を再試行」やダイアログの「保存」で再試行してください。未保存の日別入力がある間は期間・表示方式・選択日の変更やJSON取込を防ぎます。

      JSON取込は日ごとに保存するため、部分的に失敗することがあります。日ごとの「保存済み」「未保存」を確認し、保持された入力で再試行できます。同じ値を再送しても履歴は増えません。通信が途切れた場合は保存済みか確認できないので、再試行してください。「履歴同期待ち」は予定の保存済みを意味し、履歴は後から同期します。

      同期

      通常は3秒ごとに共有予定を読み込みます。フォーカス中・未保存・送信中・日本語変換中の備考は同期で上書きしません。JSON取込中は日別編集と表示移動を止め、同期結果を適用しません。オフラインでの永続保存はありません。

      取説とカレンダーの移動では画面を再読み込みせず、認証・選択日・入力・JSONプレビューを保持します。取説リンクはフォームを送信しません。備考の自動保存と同期は通常どおり継続します。ブラウザの戻る・進むも使えます。
